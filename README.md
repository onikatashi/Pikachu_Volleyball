# 피카츄 배구 (Pikachu Volleyball)

> Unity Netcode 기반 1:1 온라인 배구 게임
> 피카츄 배구 유즈맵을 모방하여 만든 1인 개발 게임

## 게임 소개

피카츄 캐릭터를 조작해 네트를 사이에 두고 1:1 배구 대결을 펼치는 2D 스포츠 게임입니다.
온라인 멀티플레이와 AI와의 싱글플레이를 모두 지원합니다.

---

## 개발 환경

- Unity 6.0 LTS
- C#
- Unity Netcode for GameObjects
- Unity Relay / Unity Lobby

---

## 핵심 컨텐츠

- **온라인 멀티플레이** : Unity Relay / Lobby 기반 온라인 1:1 대전, 방 코드로 입장
- **싱글플레이** : 물리 수식(포물선 운동 방정식) 기반 낙하 지점 예측 AI와 대전
- **스파이크 시스템** : 입력 방향에 따라 8방향 스파이크 구현
- **슬라이딩** : 낮게 날아오는 공을 받아내는 슬라이딩 기술
- **설정** : 해상도, 볼륨, 키 바인딩, 승리 점수 저장/불러오기

---

## 조작법

| 키 | 동작 |
|---|---|
| ← → | 좌우 이동 |
| ↑ | 점프 |
| Enter | 스파이크 (공중) / 슬라이딩 (지상) |

> 키 바인딩은 설정 메뉴에서 변경 가능합니다.
